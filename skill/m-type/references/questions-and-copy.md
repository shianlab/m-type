# 无记录问答与表达

以 `analyze` 返回的 questions 为准，不在脚本外重新推算缺失维度。四个可能的问题：

| index | 问题 | 选项 |
| --- | --- | --- |
| 0 | 更喜欢哪一种口味？ | C 一直喜欢的经典款 / E 没吃过的新口味 |
| 1 | 选餐时通常怎么决定？ | S 先看优惠 / F 想吃什么选什么 |
| 2 | 更常在哪个时段吃麦当劳？ | D 18:00 之前 / N 18:00 及之后 |
| 3 | 你的菜单更像哪一种？ | L 反复点那几款 / V 换着试不同组合 |

无列表时可说：“连接成功了，不过这次没有取得订单列表。可以先用几个小问题生成麦门身份，时光档案保留空白。按顺序选就好，也可以直接描述你的习惯。”然后只列返回的问题。

用户说“近期没消费”解释了查询结果，但不回答这四个偏好。不能据此选白日/夜宵或忠诚/探索。自由文本只在意思明确时映射；有歧义问对应一题。用户跳过则保留待回答状态，可按请求展示独立演示，不生成假装本人的档案。

文案直接使用 `report-model.js` 生成的 copy。固定人格宣言是角色的趣味表达；消费事实只从有效记录来。未返回列表不能说“你从没吃过麦当劳”，单笔订单不能说“你总是”，并列第一需要保留并列说明。金额默认不出现，默认没有消费等级或超过其他用户百分比。
