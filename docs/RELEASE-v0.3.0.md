# M-TYPE v0.3.0 · 麦门人格档案公开预览版

把你喜欢的那一口，存成一份麦门档案。首次公开版本包含可本地安装的 Skill、16 个复古透明角色、8 个配套背景／食物素材，以及固定 HTML 报告与手机／电脑长图导出。

## 下载选择

| 文件 | 用途 | 大小约 |
| --- | --- | --- |
| `m-type-0.3.0.zip` | 完整 Skill 安装包，Node 20+ 可直接生成 HTML | 41.1 MB |
| `m-type-demo-cases-0.3.0.zip` | 4 个模拟案例的离线 HTML、派生统计、输入与两种 PNG | 136.7 MB |
| `m-type-character-gallery.html` | 自包含交互演示，可以查看全部 16 型角色 | 55.7 MB |
| `SHA256SUMS` | 三个下载文件的 SHA-256 校验值 | 文本 |

安装请使用 `m-type-0.3.0.zip`，不要把 GitHub 自动的 Source code ZIP 当作完整安装包。操作见 [INSTALL.md](https://github.com/shianlab/m-type/blob/main/INSTALL.md)。

## 这次提供的案例

- CSNL 深夜经典守护者：24 笔模拟订单，4 种餐品。
- CSDV 白日菜单研究员：10 笔模拟订单，10 种餐品。
- EFDV 全能麦门体验官：16 笔模拟订单，12 种餐品。
- EFNV 午夜麦门探索者：0 笔订单，通过模拟回答确定人格，历史留白。

所有公开案例采用合成数据，非真实账号订单；模拟新品与标签不是官方现售菜单。图片与统计由同一套固定模板和算法生成。

## 验证与当前边界

59 项逻辑与命令行测试通过；完整 ZIP 在独立临时目录安装并运行，通过无 npm 依赖生成 HTML、缺失偏好等待、分次补答、图片校验和重复安装检查。手机／电脑 PNG 已导出；4 个案例在 320、390、1280 宽度检查无横向溢出，页面不发起外部网络请求。

官方 MCP 的开发客户端已经实测连接和一次成功只读查询，本次没有返回订单列表。非空真实订单字段核验，以及 WorkBuddy/Codex 的原生安装、技能触发和 MCP 联动仍待实测。因此本版本标记为预览版，不宣称跨客户端全流程已经通过。

Token 在宿主凭证入口填写；安装包不包含个人凭证、原始账号响应或公共订单代理。自动 PNG 需要可用的 Playwright/Chromium；无法自动导出时保留完整 HTML，可打开后手动保存长图。

独立开发创意作品，非麦当劳官方产品；素材与组件说明见 [NOTICE.md](https://github.com/shianlab/m-type/blob/main/NOTICE.md)。
